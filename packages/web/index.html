Why the error count is the wrong number

Not every failure gets pleaded

WCAG has 87 success criteria. A handful of them appear in nearly every demand letter; most appear in none. Curbcut weights each finding by how often it is actually named in accessibility complaints.

Position decides cost

An unlabelled field in a checkout form is the fact pattern that wins cases. The same failure in a footer newsletter box is not. Curbcut reads where on the page each failure sits and weights it accordingly.

Volume has diminishing returns

A hundred identical contrast errors from one bad palette token is one afternoon of work, not a hundred times the risk. The model reflects that, so the ranking stays useful instead of being dominated by whatever repeats most.

And what it cannot tell you

No automated tool can establish that a site is accessible — including this one. Automation decides roughly a third of the WCAG criteria. It can tell that an image has alt text; it cannot tell whether the alt text is right. Every Curbcut report states, in the same type size as the score, exactly which checks did not run and why.

In 2025 the FTC fined an overlay vendor $1 million for claiming its automated product delivered compliance. Meanwhile 22.6% of web accessibility suits filed in the first half of that year targeted sites that already had an overlay installed. A number that flatters you is worth less than nothing here.

How the scan works

  1. The page is fetched through a small proxy, because a browser cannot read another origin’s HTML.
  2. Every script is stripped — the page’s own JavaScript never runs.
  3. It is rendered with its real stylesheets in a sandboxed frame, so colour and size can actually be measured. Contrast is the most common failure on the web and it is invisible to any scanner that only reads markup.
  4. 105 checks run against the laid-out page using axe-core, the same engine behind Lighthouse.
  5. Findings are mapped to success criteria, to the regime you selected, and to the exposure model.

For pages behind a login, or interfaces that only exist after JavaScript runs, use the bookmarklet — it scans the page already open in front of you and nothing leaves your machine.

Who this is for

Public entities under ADA Title II

The DOJ rule set a hard date. Entities serving 50,000 or more were required to conform to WCAG 2.1 AA by 24 April 2026. Everyone else — smaller entities and every special district government — has until 26 April 2027.
